# Внутренний API статистики

## Описание

Добавлен новый эндпоинт `GET /api/internal/stats` для получения статистики сервиса сокращения URL. Эндпоинт защищен проверкой доверенной подсети.

## Конфигурация

### Параметр trusted_subnet

В конфигурационном JSON-файле добавлено новое поле:

```json
{
    "trusted_subnet": "192.168.1.0/24"
}
```

### Переменная окружения

```bash
export TRUSTED_SUBNET="192.168.1.0/24"
```

### Флаг командной строки

```bash
./api -t "192.168.1.0/24"
```

## Эндпоинт

### GET /api/internal/stats

Возвращает статистику сервиса в формате JSON:

```json
{
    "urls": 42,
    "users": 15
}
```

Где:
- `urls` - количество активных (не удаленных) сокращённых URL в сервисе
- `users` - количество уникальных пользователей в сервисе

## Безопасность

### Проверка доверенной подсети

Эндпоинт доступен только для IP-адресов, входящих в доверенную подсеть:

1. **Источник IP-адреса**: 
   - Приоритет: заголовок `X-Real-IP`
   - Fallback: `RemoteAddr` из HTTP-запроса

2. **Проверка CIDR**: 
   - IP-адрес клиента проверяется на вхождение в указанную подсеть
   - Поддерживается стандартный формат CIDR (например, `192.168.1.0/24`)

3. **Ограничения доступа**:
   - Если `trusted_subnet` не настроен (пустая строка), доступ запрещен для всех
   - Если IP не входит в доверенную подсеть, возвращается `403 Forbidden`

### Примеры конфигурации

```bash
# Разрешить доступ только из локальной сети
TRUSTED_SUBNET="192.168.1.0/24"

# Разрешить доступ только с localhost
TRUSTED_SUBNET="127.0.0.1/32"

# Разрешить доступ из нескольких подсетей (нужно настроить несколько экземпляров)
TRUSTED_SUBNET="10.0.0.0/8"
```

## Примеры использования

### Успешный запрос

```bash
curl -H "X-Real-IP: 192.168.1.100" http://localhost:8080/api/internal/stats
```

Ответ:
```json
{
    "urls": 42,
    "users": 15
}
```

### Запрос из недоверенной подсети

```bash
curl -H "X-Real-IP: 10.0.0.100" http://localhost:8080/api/internal/stats
```

Ответ:
```
HTTP/1.1 403 Forbidden
Forbidden
```

### Запрос без настройки доверенной подсети

```bash
curl http://localhost:8080/api/internal/stats
```

Ответ:
```
HTTP/1.1 403 Forbidden
Forbidden
```

## Логирование

Middleware логирует все попытки доступа:

- **Успешный доступ**: `DEBUG` уровень с информацией о клиенте
- **Отклоненный доступ**: `WARN` уровень с причиной отказа
- **Ошибки конфигурации**: `ERROR` уровень с деталями

## Совместимость

- Поддерживает IPv4 и IPv6 адреса
- Совместим с прокси-серверами (заголовок `X-Real-IP`)
- Работает со всеми типами хранилищ (Memory, File, PostgreSQL)
